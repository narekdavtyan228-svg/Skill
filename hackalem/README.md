# PermitGuard

Предсменный инспектор нарядов-допусков для промышленной площадки. Система извлекает данные из комплекта документов, сверяет их с четырьмя детерминированными mock-реестрами, применяет восемь правил безопасности и выдаёт рекомендацию с проверяемыми prooflinks. Финальное решение всегда остаётся за уполномоченным человеком.

## Что реализовано

- 60 синтетических комплектов: 40 чистых и 20 с одной контролируемой ловушкой;
- извлечение полей из PDF, JSON и CSV без сетевых вызовов;
- правила для газоанализа, допуска сотрудника, подписи, зоны, LOTO, SIMOPS, смены и полноты комплекта;
- fail-closed оркестратор и строгие Pydantic-контракты;
- Streamlit-интерфейс: просмотр PDF/JSON/CSV, журнал проверки и выгрузка заключения;
- eval по ground truth и автоматические тесты.

## Быстрый запуск

Требуется Python 3.11+.

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m eval.run
.venv\Scripts\python.exe -m streamlit run ui/app.py --server.port 8501
```

Откройте `http://localhost:8501`.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make test
make eval
make ui
```

Для базового запуска интернет и `OPENAI_API_KEY` не нужны.

Интерфейс работает с синтетическими комплектами из `data/fixtures/`. Сканированные PDF без текстового слоя и произвольные форматы документов пока не поддерживаются: отсутствие извлекаемых данных блокирует проверку.

## Команды

```bash
make smoke   # один сквозной прогон
make eval    # метрики по всем 60 комплектам
make test    # полный pytest
make data    # детерминированно пересоздать датасет
make ui      # интерфейс на порту 8501
```

Прямой запуск отдельного комплекта:

```bash
python -m core.orchestrator --permit data/fixtures/permit_0045 --print
```

## Структура

| Путь | Назначение |
|---|---|
| `core/` | схемы, mock-API, prooflinks и оркестратор |
| `data/` | генератор, ground truth и 60 комплектов |
| `extract/` | извлечение подтверждённых значений |
| `rules/` | матрица правил, движок и агрегация вердикта |
| `eval/` | расчёт приёмочных метрик |
| `ui/` | Streamlit-консоль и replay-комплект |
| `docs/` | планы, промпты и регламенты команды |

## Интерпретация результата

- `approve` означает, что автоматические барьеры не обнаружены; это не разрешение начать работы;
- `approve_with_conditions` требует выполнения перечисленных условий;
- `block_and_escalate` запрещает начало работ до решения уполномоченного руководителя;
- отсутствующие, противоречивые или непроверяемые данные всегда приводят к fail-closed блокировке.

Каждая подтверждённая находка содержит ссылку на реальный документ, страницу или строку и точную цитату. Оркестратор отбрасывает находки без валидного документального prooflink.

`python -m eval.run` проверяет также ложные блокировки чистых комплектов и возвращает ненулевой код при провале приёмки. Метрики относятся только к синтетическому набору; промышленные реестры не подключены.
